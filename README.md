Thành viên 1: Phát triển Core Server (Quản lý Mạng & Kết nối)Mục tiêu chính: Xây dựng nền tảng mạng vững chắc cho "Quản trò".Công việc cụ thể:Thiết lập kiến trúc mạng sử dụng TCP Sockets để lắng nghe và chấp nhận/từ chối kết nối từ Client.  Xây dựng hệ thống quản lý đa kết nối (Multi-threading/Concurrency) để Server có thể xử lý nhiều Client cùng lúc mà không bị nghẽn (blocking).  Xây dựng cơ chế phát hiện ngắt kết nối đột ngột: tự động phát hiện Client thoát ngang, thông báo cho toàn phòng và loại bỏ kết nối đó mà không làm treo Server (Yêu cầu bắt buộc).  (Tùy chọn) Phối hợp với Thành viên 2 để gửi các gói tin Broadcast/Multicast.

Thành viên 2: Xử lý Game Logic Server (Logic Quản trò)Mục tiêu chính: Hiện thực hóa luật chơi Ma Sói lên Server.Công việc cụ thể:Xây dựng cơ chế lưu trữ danh sách Client và trạng thái hiện tại của game (State Management).  Viết thuật toán tự động chia phe và phân vai ngẫu nhiên khi game bắt đầu.  Viết logic đồng bộ trạng thái thời gian thực: điều phối luồng game, đếm ngược ban ngày (Vote) và ban đêm (Sói cắn, Tiên tri soi).  Tính toán logic thắng/thua dựa trên hành động của các nhân vật.  Thiết kế cấu trúc gói tin (Message Protocol) bằng định dạng JSON (vd: {"type": "VOTE", "sender": "PlayerA", "target": "PlayerB"}).  

Thành viên 3: Phát triển Core Client & Network (Logic Người chơi)Mục tiêu chính: Đảm bảo Client gửi/nhận dữ liệu mượt mà, đúng chuẩn.Công việc cụ thể:Viết code kết nối đến Server thông qua IP và Port.Đóng gói (Serialize) các hành động của người chơi (vote, chat, cắn, soi) thành JSON để gửi lên Server.  Phân tích (Parse) dữ liệu JSON nhận từ Server để cập nhật trạng thái game.  Đảm bảo Client KHÔNG tự tính toán logic game, chỉ nhận lệnh từ Server.  Sử dụng cơ chế asynchronous/background worker để việc gửi/nhận gói tin mạng không làm treo giao diện GUI.  

Thành viên 4: Thiết kế GUI (Client UI/UX)Mục tiêu chính: Xây dựng giao diện ứng dụng cho người chơi (Client).Công việc cụ thể:Sử dụng nền tảng (WinForms / WPF / JavaFX / PyQt) để xây dựng Màn hình 1 (Login): Nhập IP, Port, Tên người chơi và nút Kết nối.  Xây dựng Màn hình 2 (Lobby): Hiển thị danh sách online và trạng thái chờ.  Xây dựng Màn hình 3 (In-game) gồm 3 khu vực chính: Danh sách sống/chết, Lịch sử Chat (Tổng ban ngày/Ẩn danh ban đêm), Các nút tương tác (Vote/Kỹ năng) và Đồng hồ đếm ngược.  Hỗ trợ Thành viên 3 kết nối dữ liệu mạng vào giao diện (cập nhật text, ẩn/hiện nút).

Thành viên 5: Quản lý Chất lượng (QA/Tester) & Tích hợpMục tiêu chính: Đảm bảo game chạy mượt, không lỗi và hoàn thiện file Test Cases.Công việc cụ thể:Quản lý file cấu trúc dự án (GitHub Repository), tổng hợp code của các thành viên.Viết và cập nhật chi tiết các kịch bản kiểm thử vào file Excel (Test Cases Template).Test luồng game: Thiết lập môi trường chạy 1 Server, 4-5 Client để chơi trọn vẹn 1 ván đến khi có kết quả thắng thua.  Concurrency test: Cố tình spam tin nhắn hoặc vote cùng lúc từ nhiều Client để kiểm tra nghẽn mạng.  Disconnect test (Bắt buộc): Đang chơi cố tình tắt ngang 1 Client để xem Server có bắt được lỗi và game có tiếp tục bình thường không.
